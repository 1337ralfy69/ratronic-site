# ratronic.com

Static product page, served by GitHub Pages at https://ratronic.com (CNAME file).

Deploy: push to `main`. In the repo settings, Pages -> Source: Deploy from branch `main`, folder `/ (root)`, custom domain `ratronic.com`, enforce HTTPS.

Buy buttons: replace `STRIPE_LINK_DISPLAY` and `STRIPE_LINK_BUNDLE` in `index.html` with the Stripe Payment Link URLs.
